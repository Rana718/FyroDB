# v0.2.3

Released: October 2026

v0.2.3 delivers major throughput breakthroughs across every database workload, driven by optimized lock-free concurrency, gated `io-uring` socket send batching in worker loops, test-and-test-and-set spinlock backoff, and direct zero-copy execution pipelines.

Against a 12-node Redis Cluster, a single FyroDB node reaches **122.68M Hot Key ops/sec** (76.2×), **120.49M INCR ops/sec** (18.4×), **152.20M Pub/Sub msg/sec** (18.8×), **40.21M GET ops/sec** (3.46×), and **28.32M SET ops/sec** (4.34×).

---

## Highlights

- **Record-Breaking Throughput**:
  - **120.49M INCR ops/sec** (~8.3 ns per op) under multi-client counter workloads.
  - **122.68M Hot Key ops/sec** (~8.15 ns per op) under extreme single-key contention across 100 concurrent clients.
  - **152.20M msg/sec Pub/Sub delivery** (~6.57 ns per message) with lock-free Arc snapshot subscriber fan-out.
  - **67.72M LPUSH/RPOP ops/sec** (~14.8 ns per op) via zero-allocation Quicklist chunked ring buffer recycling.
  - **62.51M HSET/HGET ops/sec** (~16.0 ns per op) for high-frequency session workloads.
  - **40.21M GET ops/sec** (~24.9 ns per op) with wait-free 14-bit hash tag filtering and zero-copy TCP stream writes.
  - **28.32M SET ops/sec** (~35.3 ns per op) and **12.14M Pipeline-64 SET ops/sec** (~82.4 ns per op).
- **io-uring Batched Completions**:
  - Network worker event loops now batch pending socket sends when ≥2 connections have unwritten data, completing ring operations together and amortizing syscall submission overhead.
- **Sub-10ns Execution Latency**:
  - Contended writes utilize test-and-test-and-set (TTAS) spinloops with exponential backoff (`MAX_SPIN_BACKOFF = 64`) and worker thread yields to eliminate cache-line bouncing.
  - Atomic counter operations mutate directly inside 64-byte L1 cache-aligned `Entry` structures without memory allocations.
- **Vector & AI Search Latency**:
  - HNSW graph ANN queries complete in **~192.5 µs** (5.2k queries/sec) with SIMD-accelerated distance kernels and thread-local scratch buffers.
  - BM25 full-text queries execute in **~24.1 µs** (41.5k queries/sec).
