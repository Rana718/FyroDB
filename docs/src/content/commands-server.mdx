## PING / ECHO

```bash
PING
PING hello
ECHO "test"
```

## INFO

```bash
INFO
# fyrodb_version:0.2.1
# connected_clients:5
# used_memory:12345678
# total_keys:50000
```

## DBSIZE / TYPE

```bash
DBSIZE
TYPE key    # "string", "hash", "list", "set", "zset", "stream", "ReJSON-RL", "none"
```

## FLUSHALL / FLUSHDB

```bash
FLUSHALL
FLUSHDB
```

## BGSAVE / SAVE / LASTSAVE

```bash
BGSAVE
SAVE
LASTSAVE    # timestamp of last successful save
```

## TIME

```bash
TIME        # [seconds, microseconds] since epoch
```

## SELECT / AUTH / QUIT / RESET

```bash
SELECT 0
AUTH password
QUIT
RESET
HELLO 2
HELLO 3     # upgrade to RESP3
```

## CLIENT

```bash
CLIENT ID
CLIENT GETNAME
CLIENT SETNAME myapp
CLIENT LIST
CLIENT INFO
```

## COMMAND

```bash
COMMAND
COMMAND COUNT
COMMAND INFO get set
```

## CONFIG

```bash
CONFIG GET *
CONFIG SET parameter value
CONFIG RESETSTAT
```

## ACL / SLOWLOG

```bash
ACL WHOAMI
ACL LIST
SLOWLOG LEN
SLOWLOG GET
SLOWLOG RESET
```
