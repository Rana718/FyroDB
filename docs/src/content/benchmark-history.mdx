## Previously published rates

These are **historical reported best-of-three** values, retained so the earlier, sometimes higher numbers remain visible. They are not freshly measured current results. See [current benchmarks](/docs/benchmarks) for the image-matched normal suite, standard clients, medians, ranges and memory evidence.

The original page described 100 clients, a pipeline of 100 and one million operations; the current Go harness uses ten million operations for KV phases. Some identical rates were repeated under both TCP and direct-engine headings. That provenance conflict is unresolved, so these figures do not establish a current TCP/engine comparison, a current competitor speedup or measured latency. Cluster counts also differed between the old README and benchmark page.

[Original benchmark page](/benchmarks/2026-11-13/historical/benchmarks.mdx.txt) · [original README](/benchmarks/2026-11-13/historical/readme.txt). The archived page's six-node cluster labels are preserved below. DiceDB was already a carried-over earlier measurement, not a matched rerun.

## How to use these figures

Do not divide a historical best sample by a current median from a different client, keyspace, payload or CPU layout. The reciprocal of an aggregate throughput rate is not measured request latency. The repeated direct-engine table from the old page has been removed from the current reference; its original text remains archived above.

Higher old peaks remain documented here, including 53.38M GET, 39.62M SET, 108.56M INCR and 113.98M deliveries/s. Their preservation does not mean the current guarded runtime reproduced every one of them.
