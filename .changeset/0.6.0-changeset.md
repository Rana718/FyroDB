# FyroDB 0.6.0 Release Notes

### Concurrency & Lock Modernization
- **`parking_lot` & Atomic Primitives**: Replaced heavy OS `std::sync::Mutex` and `RwLock` primitives with lightweight `parking_lot` locks and atomic flags (`AtomicBool`, `AtomicU64`, `ArcSwap`), accelerating lock contention throughput from 7.44 Mops/s to 76.57 Mops/s (>10x faster).
- **Dead Code Cleanups**: Purged unreferenced code and removed obsolete `#[allow(dead_code)]` annotations across the workspace.

### Storage Engine & CustomHash Probing
- **Exact-Match Probing**: Implemented `TaggedSlot::probe_entry_matching_str` and `probe_entry_matching_bytes` with circular `table.mask` wrapping across 16-slot probe windows to eliminate false tag collision misses and premature table scans.
- **Relaxed Slot Loads**: Converted probe loops to use `Relaxed` slot loads with an `Acquire` barrier only on 15-bit tag matches.
- **Optimistic Seqlock Inline String Reads**: Added seqlock validation for inline strings (≤ 23 bytes) with stack copying (`s_copy`) before serializing, eliminating two reader atomic CAS operations per read with 100% anti-tearing safety.
- **Zero-Overhead EBR Guard Drops**: Added `PENDING == 0` fast path to avoid thread-local `DIRTY` accesses when no deferred garbage is queued.
- **String Key Hinted Fast Path**: Upgraded `get_to_buf_hinted` to use direct string probing without byte slice conversion.

### Performance Gains
- **Point GET**: 8.21 Mops/s → **11.67 Mops/s** (+42.1%).
- **Point SET**: 4.74 Mops/s → **4.82 Mops/s**.
- **Mixed SET/GET (50/50)**: 37.48M ops/sec → **38.41M ops/sec**.
- **Pipeline-64 SET**: 25.71M ops/sec → **28.29M ops/sec** (+10.0%).
- **JSON.GET**: 47.26M ops/sec → **65.13M ops/sec** (+37.8%).
- **PFADD / PFCOUNT**: 248.24M ops/sec → **307.17M ops/sec** (+23.7%).
- **Hardware Core Scaling**: 6-thread GET reaches 36.30 Mops/s (5.05x scaling on 6 cores).
- **TCP Benchmark**: Over 200,000 req/sec across SET, GET, INCR, and MSET with p50 latencies of 0.127 ms.

### Concurrency & Isolation Verification
- **Anti-Tearing Test**: 72,186 writes and 54,822 reads across inline and heap strings with 0 torn reads and 0 CRC32 checksum errors.
- **Transactional Isolation**: 32,190 `MULTI`/`EXEC` transfers and 103,798 `MGET` balance audits with 0 isolation violations.
